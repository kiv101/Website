> Современное адаптивное SPA-портфолио для frontend-разработчика с переключением тем, анимациями и готовой структурой для деплоя на GitHub Pages.

![Превью сайта](https://via.placeholder.com/1200x630?text=Portfolio+Preview)

## ✨ Особенности

- 🎨 **Две темы** — светлая/темная с сохранением выбора в `localStorage`
- 📱 **Полная адаптивность** — корректное отображение на всех устройствах (mobile first)
- ⚡ **Чистый ванильный JS** — без фреймворков и лишних зависимостей
- 🖱️ **Плавная навигация** — smooth scroll с обновлением активного пункта меню
- 🃏 **Карточки проектов** — динамическая сетка с описанием, стеком технологий и ссылками
- 📄 **Скачивание резюме** — демо-функция с генерацией текстового файла
- 🎯 **SEO-оптимизация** — мета-теги, семантическая верстка
- ♿ **Доступность** — базовые ARIA-атрибуты и контрастность

## 🛠️ Технологии

| Категория       | Технологии                                                                 |
|----------------|----------------------------------------------------------------------------|
| **Разметка**    | HTML5 (семантические теги, микроформаты)                                   |
| **Стили**       | CSS3 (CSS Grid, Flexbox, CSS Variables, медиа-запросы)                    |
| **Программирование** | JavaScript ES6+ (модульная структура, работа с DOM, localStorage)     |
| **Иконки**      | Font Awesome 6 (CDN)                                                       |
| **Шрифты**      | Google Fonts (Inter)                                                       |
| **Деплой**      | GitHub Pages                                                               |
